# Release Evolution: v0.3.1 to v0.4.0

## Scope

This document is the release-evolution companion for the v0.4.0 public release.
It covers the concrete release-layer changes that move ARENA from public
synthesis support toward explicit model-evidence synthesis.

Architecture boundaries and current-layer responsibilities are defined in
`docs/facts/architecture.md`.

## Evolution Axes

From `v0.3.1` to `v0.4.0`, repository-visible evolution is centered on:

1. Stage 9 evidence synthesis in `arena run`.
2. A public `EvidenceRow` contract for preserving model-family evidence.
3. Claim routing that keeps support, counter-evidence, caveats, validation
   targets, and next-data-needed separate.
4. Runtime separation between pipeline worker count and MCMC chain count.
5. Updated GPU reporting that distinguishes physical NVIDIA hardware from JAX
   CUDA availability.
6. Robust non-parametric reporting with Mann-Whitney U plus Hodges-Lehmann
   location-shift confidence intervals.
