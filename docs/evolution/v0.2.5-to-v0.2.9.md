# Release Evolution: v0.2.5 to v0.2.9

## Scope

This document is the release-evolution companion to `docs/architecture.md`.
It covers concrete changes and release-layer rationale between `v0.2.5` and `v0.2.9`.

Architecture boundaries and current-layer responsibilities are defined in `docs/architecture.md`.

## Source of Evidence in This Repository

- `CHANGELOG.md` entries `0.2.6` through `0.2.9`
- public source tree under `src/arena/`, `scripts/`, `tests/`, `.github/workflows/`
- public reproducibility material under `sample_data/smoke/expected/` and `docs/reproducibility.md`

## Evolution Axes (Public Layer)

From `v0.2.5` to `v0.2.9`, repository-visible evolution is centered on:

1. stronger orchestration structure in `src/arena/pipeline/`
2. stronger observability and failure-visibility reporting
3. stronger config resolution/traceability behavior
4. stronger artifact/reproducibility controls (`src/arena/artifacts/` + tool layer)
5. stronger public verification surfaces (CI + smoke + verify/replay workflows)
