# Release Evolution: v0.2.9 to v0.3.0

## Scope

This document is the release-evolution companion to `docs/facts/architecture.md`.
It covers concrete changes and release-layer rationale between `v0.2.9` and `v0.3.0`.

Architecture boundaries and current-layer responsibilities are defined in `docs/facts/architecture.md`.

## Source of Evidence in This Repository

- `CHANGELOG.md` entries `0.2.9` and `0.3.0`
- public source tree under `src/arena/`, `scripts/`, `tests/`, `.github/workflows/`
- public reproducibility material under `sample_data/smoke/expected/` and `docs/facts/reproducibility.md`

## Evolution Axes (Public Layer)

From `v0.2.9` to `v0.3.0`, repository-visible evolution is centered on:

1. migration and public exposure of the synthesis subsystem (`src/arena/synthesis/`)
2. expanded verification surface (synthesis tests + Docker smoke path)
3. release-layer path isolation for real-data execution (`real-data/`, `real-output/`, `real-settings/`)
4. sample-data expansion for synthesis reproducibility (`sample_data/synthesis/`)
5. documentation reshaping for public release (`README` simplification + docs index)
